# 终端 UI 改造计划

## 目标

`gqy` 启动后进入类似 OpenCode 的 TUI 布局：
- 左侧/顶部显示 GQY-icon 图片（kitty 协议 / iTerm2 协议）
- 图片不可用时自动降级为 ANSI 彩色 "GQY" 文字 logo
- 底部为 REPL 输入区
- 整体风格：月夜主题、简洁、现代

## 当前状态

| 组件 | 现状 |
|------|------|
| Logo | `repl_avatar.rs` — 5x5 块字符 ANSI art |
| 图片协议 | `kitty_image.rs` — kitty 原生 + chafa 后备 |
| 图片嵌入 | `AVATAR_PNG = include_bytes!("../pics/GQY-avatar.png")`（死代码） |
| TUI 框架 | 无（纯 crossterm 自建） |
| REPL | `cli.rs` — `LiveReplEditor` + `read_live_repl_input()` |

### 图片显示优先级

1. **Kitty 终端** → kitty graphics protocol（已有 `kitty_image.rs`）
2. **iTerm2** → iTerm2 inline image protocol（需新增，简单）
3. **其他终端** → chafa ASCII art（已有）
4. **兜底** → ANSI 彩色 "GQY" 文字 logo（已有 `repl_avatar.rs`）

### 改动文件

| 文件 | 改动 |
|------|------|
| `src/repl_avatar.rs` | 重写：新增 `print_startup_banner()` 函数，整合图片+文字+状态信息 |

### 实现步骤

#### Step 1: 图片显示基础设施

在 `src/tools/kitty_image.rs` 新增：
```rust
/// 在终端打印 GQY icon（自动检测协议）
pub fn print_icon(png_data: &[u8], target_height: u16) -> bool
```

- 检测终端类型（`$TERM`、`$TERM_PROGRAM`）
- Kitty → kitty graphics protocol
- iTerm2 → `\e]1337;File=...` inline image
- 其他 → 调用 chafa（如果可用）
- 返回 `true` 表示图片显示成功

#### Step 2: iTerm2 inline image 协议

在 `src/tools/kitty_image.rs` 新增：
```rust
fn print_iterm2_inline(png_data: &[u8], width: u16, height: u16) -> Result<()>
```

格式：`\e]1337;File=size=<N>;width=<W>;height=<H>;preserveAspectRatio=1;inline=1:<base64>\a`

#### Step 3: 重写 `repl_avatar.rs`

```rust
/// 启动 banner：图片 + 状态信息
pub fn print_startup_banner(
    out: &mut impl Write,
    png_data: &[u8],
    provider: &str,
    model: &str,
    memory_count: usize,
    kb_count: usize,
)
```

逻辑：
1. 清屏
2. 打印空行使图片垂直居中
3. 尝试 `kitty_image::print_icon()` 居中显示图片
4. 如果成功，图片下方居中打印状态信息
5. 如果失败，居中打印 ANSI 彩色 "GQY" 文字 logo + 状态信息
6. 打印分隔线

#### Step 4: 集成到 `cli.rs`

在 `run_repl()` 中替换：
```rust
// 旧
repl_avatar::print_if_supported(&mut io::stdout());

// 新
repl_avatar::print_startup_banner(
    &mut io::stdout(),
    &repl_avatar::AVATAR_PNG,
    &config.active_provider,
    &active_model,
    memory_count,
    kb_count,
);
```

#### Step 5: 状态信息栏

在 banner 下方显示：
- 当前供应商 + 模型
- 模式（普通/计划/聊天）
- 记忆条数
- 知识库篇数
- 余额（如果有）
