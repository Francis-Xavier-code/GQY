# 迷你搜索引擎 · Wiki

一个**从零实现**、**零外部依赖**（仅 Python 标准库）的网页搜索引擎原型。
包含真实搜索引擎的完整骨架：BFS 爬虫 → 倒排索引 → BM25 排序 → 网页 UI。

> 定位：教学 / 自用搜索后端 / 可扩展原型。不是 Google 级别的分布式系统，
> 但管线每一环都是真的、能跑的。

## 核心特性

- **零依赖**：纯 Python 标准库，无需 `pip install`，跨平台即跑。
- **真实管线**：爬虫 → 索引 → 检索，端到端可运行。
- **BM25 排序**：经典概率检索模型打分，结果质量可用。
- **英文优先**：分词只处理拉丁字母+数字，刻意不碰 CJK（见[设计决策](设计决策.md)）。
- **农场黑名单**：双层（抓取端+索引端）拦截已知内容农场 / SEO 垃圾站。
- **网页 UI**：内置 `http.server` 搜索页，无前端依赖。

## 目录结构

```
searchengine/
├── cli.py          命令行入口（crawl / index / search / serve）
├── crawler.py      BFS 爬虫 + 域名黑名单
├── indexer.py      倒排索引构建 + 标题加权
├── query.py        BM25 检索排序 + 摘要高亮
├── tokenizer.py    英文优先分词器
├── server.py       网页搜索 UI
├── wiki/           本文档
└── data/           运行时数据（crawl/ 原始页，index/ 索引，blacklist.txt）
```
