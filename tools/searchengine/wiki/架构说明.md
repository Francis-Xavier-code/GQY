# 架构说明

搜索引擎由四条管线与六个模块组成。全部为纯标准库实现。

## 管线总览

```
        种子 URL
            │
   ┌────────▼────────┐
   │   crawler.py     │  BFS 抓取：robots 尊重、限速、英文过滤、黑名单拦截
   │  （采集层）      │  → data/crawl/manifest.jsonl + raw/*.html
   └────────┬────────┘
            │
   ┌────────▼────────┐
   │   indexer.py    │  HTML 正文抽取 → 标题加权 → 倒排索引
   │  （索引层）      │  → data/index/{docs.jsonl, postings.json, stats.json}
   └────────┬────────┘
            │
   ┌────────▼────────┐
   │    query.py     │  BM25 打分 + Top-K + 命中摘要高亮
   │  （检索层）      │
   └────────┬────────┘
            │
   ┌────────▼────────┐
   │ server.py / CLI │  网页 UI 或命令行呈现结果
   └─────────────────┘
```

## 模块职责

### tokenizer.py — 分词器（最底层）
- 只匹配拉丁字母+数字（`[a-zA-Z0-9][a-zA-Z0-9._+#-]*`），转小写。
- **不处理 CJK**（详见[设计决策](设计决策.md)）。
- 提供 `tokenize(text) -> list[str]` 与 `term_freq(tokens) -> dict`。

### crawler.py — 爬虫（采集层）
- `crawl(...)`：BFS 遍历，受 `max_pages` / `max_depth` 限制。
- `RobotsCache`：解析 `robots.txt` 的 `Disallow`（支持 `*` 通配），礼貌抓取。
- `looks_english(html)`：按 `<html lang>` 或正文拉丁占比（≥55%）判断是否英文页，
  非英文页直接跳过（英文优先策略的采集端实现）。
- `DomainBlocklist`：后缀匹配的域名黑名单，抓取前拦截黑名单域且**不入队其外链**。
- `extract_links(html, base)`：从 `<a href>` 抽取并归一化链接。
- `POLITE_DELAY = 1.0`：默认 1 请求/秒限速。

### indexer.py — 索引器（索引层）
- `build_index(manifest_path, out_dir, blocklist=None)`：
  1. `_strip_html` 抽取 `<title>` 与正文（去 script/style/标签）。
  2. 标题加权（`TITLE_BOOST = 3.0`）：标题命中等同正文多次命中。
  3. 分词 → 词频 → 倒排索引 `term -> {doc_id: tf}`。
  4. 防御层：若传入 `blocklist`，黑名单域文档直接跳过（`skipped_blacklist` 计数）。
  5. 输出 docs / postings / stats 三个文件。
- 统计项：`N`（文档数）、`avg_len`（平均长度）、`total_terms`。

### query.py — 检索器（检索层）
- `load_index(index_dir)`：载入倒排索引与文档表。
- `search(idx, query, top_k=10)`：
  - 查询分词 → 逐词 BM25 打分（公式见下）。
  - 多词查询对重复词弱加权。
  - 返回 `{doc_id, url, title, score, snippet}`，`snippet` 含 `<mark>` 高亮。
- **BM25 公式**：
  ```
  idf(t) = ln(1 + (N - df + 0.5) / (df + 0.5))
  score  = Σ idf(t) · (tf·(k1+1)) / (tf + k1·(1 - b + b·|D|/avgdl))
  ```
  其中 `k1 = 1.5`，`b = 0.75`。

### server.py — 网页 UI（呈现层）
- 基于 `http.server.BaseHTTPRequestHandler`，单文件、无前端依赖。
- `run(index_dir, host, port)`：加载索引，`/?q=...` 渲染结果页。
- 结果模板含标题、URL、`<mark>` 高亮摘要。

### cli.py — 命令行入口（编排层）
- 子命令：`crawl` / `index` / `search` / `serve`。
- `_build_blocklist(args)`：统一构建 `DomainBlocklist`（默认清单 + 可选自定义文件）。

## 数据格式

`data/crawl/manifest.jsonl`（每行）：
```json
{"url":"https://example.com","file":"data/crawl/raw/ab12cd.html","status":200,"depth":0,"ts":1691...}
```

`data/index/docs.jsonl`（每行）：
```json
{"doc_id":0,"url":"https://example.com","title":"Example Domain","length":3497,"file":"data/crawl/raw/ab12cd.html"}
```

`data/index/stats.json`：
```json
{"N":12,"avg_len":3496.6,"total_terms":41932}
```
