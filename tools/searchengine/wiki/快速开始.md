# 快速开始

环境要求：**Python 3.9+**（本项目用 3.9.6 实测；代码已避开 3.10+ 才支持的语法）。
无需安装任何第三方包。

## 1. 进入项目

```bash
cd /path/to/searchengine
python3 --version   # 确认 >= 3.9
```

## 2. 抓取网页

从种子 URL 出发做 BFS 抓取：

```bash
python3 cli.py crawl https://example.com https://www.iana.org/help/example-domains \
    --pages 50 --depth 2
```

- `--pages`：最多抓多少页（默认 50）
- `--depth`：BFS 最大深度（默认 2）
- 默认开启 **英文优先**（`--no-english-only` 关闭）与 **农场黑名单**
  （`--no-blacklist` 关闭，`--blacklist-file` 指定自定义黑名单）

抓取结果落在 `data/crawl/`：
- `manifest.jsonl`：每页一行元数据 `{url, file, status, depth, ts}`
- `raw/<hash>.html`：原始页面

## 3. 构建索引

```bash
python3 cli.py index
```

读取 `data/crawl/manifest.jsonl`，抽取正文、分词、构建倒排索引，输出到 `data/index/`：
- `docs.jsonl`：文档元数据（含标题、长度、URL）
- `postings.json`：倒排索引 `term -> {doc_id: tf}`
- `stats.json`：全局统计 `N / avg_len / total_terms`

若想换自定义黑名单重建：
```bash
python3 cli.py index --blacklist-file my_blacklist.txt
```

## 4. 命令行检索

```bash
python3 cli.py search "example domain" --top 10
```

输出每篇结果的 BM25 分数、标题、URL、命中摘要（`<mark>` 高亮）。

> 中文查询会优雅降级：因分词器不处理 CJK，直接返回零结果，不会报错。

## 5. 启动网页 UI

```bash
python3 cli.py serve --port 8080
```

浏览器打开 http://127.0.0.1:8080 ，输入查询即可得到 BM25 排序的结果页。

## 完整流程示意

```
cli.py crawl  →  data/crawl/manifest.jsonl + raw/*.html
        ↓
cli.py index  →  data/index/{docs.jsonl, postings.json, stats.json}
        ↓
cli.py search "query"   或   cli.py serve
```

## 常见问题

**Q：爬取很慢？**
默认限速 1 请求/秒（礼貌抓取）。可在 `crawler.py` 调小 `POLITE_DELAY`，但请对目标站点保持友好。

**Q：中文搜不到？**
这是设计选择——英文优先策略下不索引中文。如需中文，见[设计决策](设计决策.md)与[扩展指南](扩展指南.md)。

**Q：想搜自己的站点全集？**
调大 `--pages` 与 `--depth`，并确保种子在同域内（`same_domain_only` 默认开启）。
