# 记忆系统

GQY 的记忆系统基于 Cindy Memory，提供持久化的记忆存储、搜索和回忆功能。记忆系统让 GQY 能够记住用户的偏好、重要事实和对话历史，提供更加个性化的服务。

## 核心功能

### 1. 事实记忆（Facts）
- **记住事实**：从对话中提取重要信息并持久化存储
- **自动记忆**：识别"请记住"、"别忘了"等关键词自动记录
- **记忆衰减**：长期不访问的记忆会逐渐降低权重
- **记忆遗忘**：支持手动删除不需要的记忆

### 2. 情景记忆（Episodes）
- **对话记录**：自动记录重要对话片段
- **上下文关联**：将相关对话关联起来
- **时间戳标记**：记录记忆发生的时间

### 3. 搜索与回忆
- **语义搜索**：基于内容相似度搜索记忆
- **关键词搜索**：支持精确关键词匹配
- **上下文回忆**：根据当前对话回忆相关记忆

## 使用方法

### 命令行工具

```zsh
# 记住一个事实
gqy memory remember "用户喜欢使用 Rust 编程"

# 搜索记忆
gqy memory search "编程偏好"

# 列出所有记忆
gqy memory list

# 删除记忆
gqy memory forget "过时的信息"

# 清空所有记忆
gqy memory clear
```

### 对话中使用

在对话中，GQY 会自动识别并记忆重要信息：

```
用户：请记住我是一名数据科学家，专注于机器学习
GQY：好的，我已经记住您是一名专注于机器学习的数据科学家。
```

### 自动记忆触发

GQY 会自动识别以下模式并触发记忆：
- "请记住..."
- "别忘了..."
- "我是一名..."
- "我喜欢..."
- "我讨厌..."
- "我的工作是..."

## 配置选项

### 记忆配置（config.jsonc）

```jsonc
{
  "memory": {
    "enabled": true,
    "auto_fact_enabled": true,
    "auto_diary_enabled": true,
    "evicted_context_enabled": true,
    "decay_days": 90,
    "max_memories": 10000
  }
}
```

### 配置说明

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `enabled` | `true` | 启用记忆系统 |
| `auto_fact_enabled` | `true` | 启用自动事实记忆 |
| `auto_diary_enabled` | `true` | 启用自动情景记忆 |
| `evicted_context_enabled` | `true` | 启用上下文驱逐记忆 |
| `decay_days` | `90` | 记忆衰减天数 |
| `max_memories` | `10000` | 最大记忆数量 |

## 存储结构

### 数据目录
```
GQY_HOME/data/memory/
├── memory.db          # 主记忆数据库
├── facts/             # 事实记忆
├── episodes/          # 情景记忆
└── index/             # 搜索索引
```

### 数据库表结构
- **facts**：存储事实记忆
  - `id`：唯一标识
  - `content`：记忆内容
  - `source`：来源（对话/命令/自动）
  - `status`：状态（active/forgotten）
  - `confidence`：置信度
  - `recall_count`：回忆次数
  - `created_at`：创建时间
  - `updated_at`：更新时间

- **episodes**：存储情景记忆
  - `id`：唯一标识
  - `user_message`：用户消息
  - `assistant_message`：助手回复
  - `created_at`：创建时间

## 高级功能

### 记忆衰减
- 长期不访问的记忆会逐渐降低权重
- 衰减周期可通过 `decay_days` 配置
- 衰减后的记忆仍可被搜索到，但排名较低

### 记忆关联
- 相关记忆会自动关联
- 回忆一个记忆时，会同时显示相关记忆
- 支持手动建立记忆关联

### 记忆导出
```zsh
# 导出所有记忆
gqy memory export --format json --output memories.json

# 导入记忆
gqy memory import --file memories.json
```

## 最佳实践

### 1. 明确记忆指令
使用明确的指令帮助 GQY 识别重要信息：
```
✅ "请记住我是一名数据科学家"
❌ "我是一名数据科学家"（可能不会被自动记忆）
```

### 2. 定期清理记忆
定期清理过时或不准确的记忆：
```zsh
# 查看记忆统计
gqy memory stats

# 清理过时记忆
gqy memory cleanup
```

### 3. 使用搜索功能
充分利用搜索功能回忆相关信息：
```zsh
# 搜索相关记忆
gqy memory search "机器学习 项目"

# 按时间搜索
gqy memory search --since "2024-01-01"
```

## 故障排除

### 记忆系统不工作
1. 检查配置：`gqy config get memory.enabled`
2. 检查数据库：`ls -la GQY_HOME/data/memory/`
3. 重建索引：`gqy memory reindex`

### 搜索结果不准确
1. 更新搜索索引：`gqy memory reindex`
2. 调整搜索参数：`gqy memory search --limit 20 --threshold 0.5`
3. 检查记忆质量：`gqy memory stats`

### 记忆丢失
1. 检查备份：`ls -la GQY_HOME/backups/`
2. 恢复记忆：`gqy memory restore --from-backup`
3. 检查存储空间：`df -h GQY_HOME/`
