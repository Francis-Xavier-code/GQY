# 工具系统

GQY 的工具系统提供了丰富的内置工具，支持工具注册、加载和权限管理。工具系统是 GQY 执行各种任务的核心组件。

## 核心概念

### 1. 工具类型
- **内置工具**：GQY 自带的工具
- **自定义工具**：用户注册的脚本工具
- **技能工具**：通过技能系统加载的工具
- **MCP 工具**：通过 MCP 协议加载的工具

### 2. 工具层级
- **完整工具集**：Normal 模式，包含所有工具
- **只读工具集**：Plan 模式，不包含写入工具
- **聊天工具集**：Chat 模式，只包含轻量工具

### 3. 工具权限
- **自动授权**：安全工具自动授权
- **用户授权**：需要用户确认的工具
- **禁止使用**：被禁用的工具

## 工具注册

### 自动注册
GQY 启动时会自动注册所有内置工具：

```zsh
# 查看已注册工具
gqy tools list

# 查看工具详情
gqy tools info web_search
```

### 手动注册
可以手动注册自定义工具：

```zsh
# 注册脚本工具
gqy scripts register my-script.sh --name "我的脚本" --description "自定义脚本工具"

# 注册技能工具
gqy skills register my-skill --name "我的技能" --description "自定义技能"
```

### 工具加载模式
- **立即加载**：启动时加载所有工具
- **懒加载**：按需加载工具
- **混合加载**：常用工具立即加载，其他懒加载

## 工具权限

### 权限级别
- **自动授权**：安全工具，无需用户确认
- **用户授权**：需要用户确认的工具
- **禁止使用**：被禁用的工具

### 权限配置
```jsonc
{
  "tools": {
    "enabled": true,
    "max_rounds": 10,
    "loading_mode": "hybrid",
    "permissions": {
      "run_command": "user",
      "write_file": "user",
      "read_file": "auto"
    }
  }
}
```

### 权限说明
| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `enabled` | `true` | 启用工具系统 |
| `max_rounds` | `10` | 最大工具调用轮数 |
| `loading_mode` | `hybrid` | 工具加载模式 |
| `permissions` | `{}` | 工具权限配置 |

## 自定义工具

### 脚本工具
```bash

# my-script.sh
# 自定义脚本工具
```

注册脚本工具：
```zsh
gqy scripts register my-script.sh --name "我的脚本" --description "自定义脚本工具"
```

```jsonc
// my-skill.json

  "name": "我的技能",
  "description": "自定义技能",
```

注册技能工具：
```zsh
gqy skills register my-skill.json
```

## 工具调用

### 自动调用
GQY 会根据对话内容自动调用合适的工具：

```
用户：今天北京天气怎么样？
GQY：让我查一下北京天气。
     [调用 weather 工具]
     北京今天晴，气温 25°C...
```

### 手动调用
用户可以手动调用工具：

```zsh
# 调用天气工具
gqy tool weather --city "北京"

# 调用搜索工具
gqy tool web_search --query "Rust 编程"
```

## 工具监控

### 工具统计

```zsh
# 查看工具使用统计
gqy tools stats
```

```zsh
# 查看工具日志
```

## 最佳实践

### 1. 合理使用工具
根据任务选择合适的工具：
```
✅ 使用 weather 工具查询天气
❌ 使用 web_search 工具查询天气（效率低）
```

### 2. 控制工具调用
避免不必要的工具调用：
```
✅ 一次调用完成任务
❌ 多次调用同一工具
```

### 3. 权限管理
合理配置工具权限：
```jsonc
{
  "tools": {
    "permissions": {
      "run_command": "user",  // 需要用户确认
      "read_file": "auto"     // 自动授权
    }
  }
}
```

## 故障排除

### 工具不工作
1. 检查工具是否启用：`gqy tools list`
2. 检查工具权限：`gqy tools info 工具名`
3. 检查工具日志：`cat GQY_HOME/logs/tools.log`

### 工具调用失败
1. 检查参数是否正确：`gqy tools info 工具名`
2. 检查工具依赖：`gqy tools check 工具名`
3. 重新注册工具：`gqy scripts register 脚本路径`

### 工具性能问题
1. 检查工具执行时间：`gqy tools stats`
2. 优化工具实现
3. 减少工具调用次数
