# GQY 架构说明

本文档介绍 GQY 的系统架构、核心组件和设计原则。

## 系统概览

GQY 是一个基于 Rust 构建的 AI 助理系统，采用模块化架构设计，支持多种交互方式和扩展机制。

### 核心特性

- **多通道交互**: 终端、Web、QQ、Telegram
- **模块化设计**: 插件化工具系统
- **持久化存储**: SQLite 数据库
- **可扩展性**: 自定义工具和技能

## 核心组件

### 1. 用户交互层

#### Terminal (REPL)
- 交互式命令行界面
- 流式输出支持
- 快捷键绑定
- 历史命令记录

#### WebUI (SSE)
- 基于 Axum 的 Web 服务器
- Server-Sent Events 实时通信
- 多会话管理
- 图片上传支持

#### 桥接系统
- QQ 桥接 (NapCat)
- Telegram 桥接
- 独立对话通道
- LaunchAgent 自启

### 2. 命令分发层

#### CLI 命令
- 参数解析 (clap)

## 数据流

### 1. 用户输入流

```
用户输入 → 命令分发 → Agent 核心 → LLM 通信 → 工具调用 → 响应生成
```

### 2. 工具调用流

```
Agent 请求 → 工具注册表 → 权限检查 → 工具执行 → 结果返回 → Agent 处理
```

### 3. 记忆关联流

```
用户消息 → 记忆搜索 → 相关记忆 → 上下文注入 → LLM 处理 → 响应生成
```

### 4. 备份恢复流

```
状态变更 → Git 快照 → 远程同步 → 冲突解决 → 状态恢复
```

### 1. 模块化设计
- 组件间低耦合
- 接口清晰定义
- 易于扩展和维护

### 2. 插件化架构
- 工具插件化
- 技能可扩展
- 通道可插拔

### 3. 持久化存储
- SQLite 数据库
- Git 版本控制
- 文件系统存储

### 4. 可扩展性
- 自定义工具
- 自定义技能
- 自定义通道

### 5. 安全性
- 权限控制
- 数据加密
- 访问授权

## 技术栈

### 核心语言
- **Rust**: 系统编程语言
- **Tokio**: 异步运行时
- **Axum**: Web 框架

### 数据存储
- **SQLite**: 关系数据库
- **rusqlite**: Rust SQLite 绑定
- **Git**: 版本控制

### 通信协议
- **HTTP/HTTPS**: Web 通信
- **SSE**: 实时通信
- **WebSocket**: 双向通信

### 序列化
- **JSON**: 数据交换
- **JSONC**: 配置文件
- **Serde**: 序列化框架
