# 常见问题

## 本地模型相关

### Q：为什么本地模型回复很慢（1-2 分钟）？

Qwen3 系列默认开启 thinking（思考模式），8B 模型思考 330 token 要 1 分多钟。解决：

1. 关思考：llama.cpp 用 no-think 模板 / Ollama 用 `enable_thinking false` 副本（见 [本地模型部署](本地模型部署)）
2. 8B 模型 + 全量工具集（30 个）会陷入工具调用循环：**在闲聊模式用本地模型**（轻量工具集）

### Q：菜单栏打开后本地模型没起来？

菜单栏启动时会自动拉起 llama-server（127.0.0.1:8080）。检查：

```zsh
curl http://127.0.0.1:8080/v1/models
gqy provider list    # 当前激活是否 llamacpp
```

如果 8080 无响应，确认 `~/llama-models/qwen3-abliterated-8b-q4.gguf` 存在、`brew list llama.cpp` 已装。

### Q：模型输出带 `<think>` 标签？

0.8.3+ 会自动剥除，无需处理。如果还看到，确认 `gqy --version` >= 0.8.3。

## 人格相关

### Q：切了闲聊模式还是"不能恋爱模拟"？

大概率人格文件没被读到（历史坑：放错路径）：

```zsh
ls ~/Library/Application\ Support/gqy/prompts/    # 必须有 lover.md / chat.md
gqy config set prompt.active_persona lover.md
```

WebUI 顶栏应显示 **💗 lover** 徽标。改完开新对话生效（每轮对话前重读人格文件）。

### Q：WebUI 不显示女友人格？

- 顶栏人格徽标来自 `/api/config` 的 `prompt.active_persona`
- 确认 config.jsonc：`"active_persona": "lover.md"`
- 确认文件在 `.../gqy/prompts/`（不是 `.../gqy/config/prompts/`）

## WebUI 相关

### Q：WebUI 的模型列表/配置不对？

多半是**旧版 gqy web 进程**占着 4096 端口：

```zsh
curl http://127.0.0.1:4096/api/health   # 看 version
lsof -i :4096                            # 找到旧进程 kill 掉
# 然后菜单栏或 gqy web 重新拉起
```

### Q：修改 config.jsonc 后 WebUI 不刷新？

config watcher 会自动 reload（发布 `config.reloaded` 事件）。也可手动点顶栏「重新加载配置」。

## 供应商相关

### Q：加了供应商但对话里找不到模型？

`gqy provider add` 会自动发现模型（GET /models）。如果发现失败（非 OpenAI 兼容端点），手动指定：

```zsh
gqy provider add <url> --api-key <key> --model <model-name>
```

### Q：API key 安全吗？

- WebUI 返回的配置会**脱敏** key（`/api/config` 只返回 has_key 布尔）
- 桥文件/配置文件避免硬编码真实密钥（环境变量注入）
- tap 仓库发布前用 `git grep -E "sk-[A-Za-z0-9]{10,}"` 检查

## 其他

### Q：gqy menubar --install 装到哪了？

`~/Applications/顾清影.app`（不是 /Applications）。旧的 cask 版在 /Applications 可删。

### Q：本地数据会不会传到云端？

隐私数据（训练样本 `data/finetune/turns.jsonl`、生成脚本）已 gitignore，不会进 git/发布。对话记忆走你自己的私有 Git 远程（自选）。
