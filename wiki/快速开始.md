# 快速开始

## 安装

```zsh
brew tap Francis-Xavier-code/GQY
brew trust Francis-Xavier-code/GQY   # Homebrew 新版要求信任非官方 tap
brew install gqy
```

从源码构建（开发）：

```zsh
git clone https://github.com/Francis-Xavier-code/GQY.git
cd GQY
cargo build --release
./target/release/gqy
```

## 三条使用路径

| 路径 | 命令 | 适合 |
|---|---|---|
| 终端 | `gqy`（REPL，Tab 切模式）| 极客、脚本 |
| WebUI | `gqy web` 或 ⌥H | 日常聊天、看用量 |
| 菜单栏 | `gqy menubar --install` | 常驻、悬浮卡片 |

## 五分钟上手

1. `gqy` 进终端 REPL，随便聊两句
2. `gqy models` 看当前模型；配好本地模型后 `gqy models 2` 切换
3. WebUI 顶栏切到**闲聊模式**，体验女友人格（先确认顶栏有 💗 徽标）
4. `gqy provider add <url> --api-key <key>` 接入你自己的服务商
5. 想让她记得你：配置私有 Git 远程（记忆自动备份）

## 常用命令速查

```zsh
gqy                 # REPL 对话
gqy "消息"          # 单轮对话
gqy models          # 列出/切换模型
gqy provider ...    # 供应商管理（add/list/switch/remove）
gqy web             # WebUI
gqy menubar --install
gqy tts "文字"      # 语音朗读
gqy stt 音频文件    # 语音识别
gqy kb add <目录>   # 知识库导入
gqy config          # 配置 TUI
gqy config set <key> <value>   # 配置修改（自动建段）
gqy backup now      # 手动备份
```

## 目录约定

- 配置/记忆/数据：`GQY_HOME`（默认 `~/Library/Application Support/gqy`）
- 人格：`$GQY_HOME/prompts/`（lover.md / chat.md）
- 配置：`$GQY_HOME/config.jsonc`
- 对话库：`$GQY_HOME/conversation.db`
- 本地模型：`~/llama-models/`（llama.cpp GGUF + no-think 模板）
