# WebUI 指南

WebUI 是 GQY 的主要图形界面（`gqy web`，默认端口 4096）。菜单栏按 ⌥H 在浏览器打开，左键/⌥G 打开悬浮卡片（panel 模式 `?panel=1`）。

## 打开方式

```zsh
gqy web                # 启动并打开浏览器
gqy web --no-open      # 只启动服务
gqy menubar --install  # 菜单栏（⌥H 浏览器 / 左键悬浮卡片 / ⌥G 唤起）
```

## 顶栏

- **💗 人格徽标**：当前激活人格（如 lover.md），确认女友人格是否生效
- **备份徽标**：最近一次备份结果（成功/失败/时间）
- **模型下拉**：全部可用模型，当前激活带 ✓；会话级切换
- **重新加载配置**：config.jsonc 被外部修改后手动刷新（config watcher 通常已自动处理）

## 对话模式（普通 / 计划 / 闲聊）

顶栏 `mode-switch` 三个按钮。切到闲聊模式后：

- 加载 chat.md 女友态提醒
- 上下文与普通/计划隔离（最近 12 轮）
- 历史列表按模式过滤（后端 `?mode=` 参数）

## 用量分析面板

右下角 **📊** 按钮打开：

- GitHub 式贡献热力图（52 周 × 7 天）
- 费用估算（元，按 provider 单价表，可点击「单价」修改，存 localStorage）
- token 构成（近 30 天 prompt/completion/cache 堆叠柱）
- 模型维度表 + 调用级明细（能看到"烧钱"的那次调用）

数据来自 `/api/usage/stats` 与 `/api/usage/details`。

## 悬浮卡片（panel 模式）

菜单栏左键打开 430×580 悬浮卡片（NSPanel + WKWebView），加载 `?panel=1` 精简界面：隐藏侧栏/顶栏，单聊卡片形态。点别处自动收起（`hidesOnDeactivate`）。

## 常见操作

| 操作 | 方式 |
|---|---|
| 切换供应商 | 顶栏模型下拉 / 对话说「切到 xx」 |
| 查看/编辑配置 | 顶栏配置按钮（结构化表单 + JSON 草稿）|
| 导出对话 | 顶栏下载按钮 |
| 刷新配置 | 顶栏「重新加载配置」/ 重启 `gqy web` |
| 旧进程排查 | `lsof -i :4096` + `/api/health` 看版本 |
