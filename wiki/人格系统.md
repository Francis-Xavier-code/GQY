# 人格系统

GQY 的人格由 `GQY_HOME/prompts/` 目录下的 Markdown 文件驱动，**改文件即生效**（每轮对话前重新读取，无需重启）。

## 文件与作用

| 文件 | 作用 | 生效范围 |
|---|---|---|
| `lover.md` | 完整女友人格（基础人设）| 所有模式的基础人格 |
| `chat.md` | 女友态闲聊提醒 | 闲聊（Chat）模式追加 |
| `gqy.md` | 内置默认人格（编译期内嵌）| `active_persona` 为空时的兜底 |

## 激活人格

```jsonc
// GQY_HOME/config.jsonc
"prompt": {
  "prompts_dir": "prompts",
  "active_persona": "lover.md"   // 置空 = 使用内置 gqy.md
}
```

CLI 修改：

```zsh
gqy config set prompt.active_persona lover.md
```

WebUI 顶栏会显示 **💗 人格徽标**（`lover.md` 等），一眼确认人格是否生效。

## 三个对话模式

| 模式 | 触发 | 人格 | 工具集 |
|---|---|---|---|
| 普通 Normal | WebUI 顶栏 / REPL Tab | 基础人格 | 全量工具 |
| 计划 Plan | `gqy --plan` | 基础人格 + 计划提醒 | 只读工具 |
| 闲聊 Chat | WebUI 顶栏 / REPL Tab | 基础人格 + chat.md 女友态 | 轻量工具（fetch/web/视觉/表情/记忆只读）|

## 闲聊隔离

闲聊模式的对话写入 `mode='chat'` 存储，与普通/计划模式**互不污染**：

- 闲聊上下文只看最近 **12 轮**（本地模型上下文友好）
- 普通/计划模式的上下文排除闲聊轮次（闲聊不撑爆正经对话）
- WebUI 切换模式时按模式重载历史（`/api/channels/{id}/turns?mode=`）
- 终端 REPL 用 **Tab** 循环切换模式

## 人格写法要点

- 人格文件是纯 Markdown，直接作为 system prompt 注入
- 想让人格在亲密对话放得开：无审查模型 + 明确授权（`lover.md` 中"情感与文字层面的亲近是被允许的（主人授权）"）
- 内置 `gqy.md` 的"禁止恋爱模拟"是条件式：女友人格或闲聊模式启用时自动放行

## 注意

人格文件放在 **`~/Library/Application Support/gqy/prompts/`**（GQY 的 config_dir 是 `.../gqy` 本身，不要多套一层 `config/`）。
