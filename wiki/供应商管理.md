# 供应商管理

GQY 支持**任意数量**的 OpenAI 兼容供应商（云端 API 或本地服务），可在对话里自然语言热切换，无需重启。

## CLI 命令

```zsh
# 添加供应商：自动 GET /models 发现可用模型 → 写入配置 → 激活默认模型
gqy provider add https://api.deepseek.com/v1 --api-key sk-xxx
gqy provider add http://127.0.0.1:8080/v1 --api-key local --id llamacpp --name "llama.cpp 本地"

# 列出全部供应商（key 脱敏）+ 当前激活
gqy provider list

# 热切换
gqy provider switch deepseek --model deepseek-chat

# 移除
gqy provider remove <id>
```

## 对话自然语言（manage_providers 工具）

在 WebUI 或终端直接跟她说：

> 「帮我加个供应商，地址 https://api.xxx.com/v1，key 是 sk-xxx」
> 「切换到 Ollama」
> 「现在有哪些供应商？」
> 「把 xx 删掉」

她通过 `manage_providers` 工具完成：发现模型 → 写配置 → 激活。工具在普通/计划模式可用（闲聊保持轻量）。

## 热切换机制

1. 写盘 `config.jsonc`（`active_provider` + `active_provider_models`）
2. GQY 的 **config watcher** 检测到文件变化 → 自动 reload agent 的 LLM client → 发布 `config.reloaded` 事件
3. WebUI 自动刷新模型下拉，无需重启

## 内置预设

`ollama`（localhost:11434）、`lmstudio`（localhost:1234）以及 openai / anthropic / deepseek / gemini / openrouter 等模板已内置，填入 key / models 即可用。

## WebUI 模型下拉

顶栏模型按钮列出**配置了 models 列表**的供应商（`provider_model_choices`）。当前激活项带 ✓。如果 WebUI 显示的不是最新配置，先检查是否有旧版 gqy web 进程占着 4096 端口：

```zsh
curl http://127.0.0.1:4096/api/health   # 看 version 是否最新
lsof -i :4096                            # 旧进程 kill 掉即可
```
