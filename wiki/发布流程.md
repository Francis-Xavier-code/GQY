# 发布流程

GQY 通过 Homebrew tap 发布。每次发布包含：主仓库 tag + GitHub Release + tap 仓库 formula/cask 更新 + 本机 `brew upgrade`。

## 前置

- `gh` 已登录（`gh auth status`）
- tap 仓库 `homebrew-gqy` 已 clone 到 `/opt/homebrew/Library/Taps/francis-xavier-code/homebrew-gqy`

## 步骤

### 1. 版本 bump

```zsh
sed -i '' 's/^version = "X.Y.Z"/version = "X.Y.Z+1"/' Cargo.toml
sed -i '' 's/version "X.Y.Z"/version "X.Y.Z+1"/' Casks/gqy.rb
# CHANGELOG.md 顶部加新版本条目（Keep a Changelog 格式）
```

### 2. 构建验证

```zsh
cargo build --release
zsh macos/GQYMenuBar/build.sh && zsh macos/GQYMenuBar/make-dmg.sh   # dmg
```

### 3. commit + tag + push + release

```zsh
git add -A && git commit -m "feat: 0.8.4 ..."
git tag vX.Y.Z && git push origin main && git push origin vX.Y.Z
gh release create vX.Y.Z --title "vX.Y.Z" --notes "..."
gh release upload vX.Y.Z macos/GQYMenuBar/.build/GQY-X.Y.Z.dmg
```

### 4. 计算 sha256 + 更新 formula/cask

```zsh
curl -Ls https://github.com/Francis-Xavier-code/GQY/archive/refs/tags/vX.Y.Z.tar.gz | shasum -a 256
shasum -a 256 macos/GQYMenuBar/.build/GQY-X.Y.Z.dmg
# 填入 Formula/gqy.rb（tarball）和 Casks/gqy.rb（dmg），commit + push
```

### 5. 同步 tap 仓库

更新 `/opt/homebrew/Library/Taps/francis-xavier-code/homebrew-gqy/Formula/gqy.rb` 的 url + sha256，commit + push。

### 6. 本机升级

```zsh
brew upgrade gqy
gqy menubar --install      # 菜单栏同步（如果 main.m 有改动）
```
