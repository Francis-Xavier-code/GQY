# 发布流程

GQY 通过 Homebrew tap + 一键安装脚本发布。推送 tag 后 CI 自动构建多平台二进制并创建 GitHub Release。

## 前置

- `gh` 已登录（`gh auth status`）
- tap 仓库 `homebrew-gqy` 已 clone 到 `/opt/homebrew/Library/Taps/gqyteam/homebrew-gqy`

## 步骤

### 1. 版本 bump

```zsh
# 更新 Cargo.toml 版本号
sed -i '' 's/^version = "X.Y.Z"/version = "X.Y.Z+1"/' Cargo.toml
# CHANGELOG.md 顶部加新版本条目（Keep a Changelog 格式）
```

### 2. 构建验证

```zsh
cargo build --release
cargo test
```

### 3. commit + tag + push

```zsh
git add -A && git commit -m "release: vX.Y.Z"
git tag vX.Y.Z && git push origin main && git push origin vX.Y.Z
```

推送 tag 后 `.github/workflows/release.yml` 自动：
- 构建 4 个平台的二进制（macOS ARM/x86、Linux x86/arm64）
- 打包为 `gqy-{target}.tar.gz`
- 从 CHANGELOG 提取 release notes
- 创建 GitHub Release 并上传资产

### 4. 更新 Homebrew formula

```zsh
# 计算源码 tarball sha256
curl -Ls https://github.com/GQYTeam/GQY/archive/refs/tags/vX.Y.Z.tar.gz | shasum -a 256
# 填入 Formula/gqy.rb，commit + push
```

### 5. 同步 tap 仓库

更新 `/opt/homebrew/Library/Taps/gqyteam/homebrew-gqy/Formula/gqy.rb` 的 url + sha256，commit + push。

### 6. 本机升级

```zsh
brew update && brew upgrade gqy
```

## 安全清单

- [ ] 桥文件/配置文件无真实密钥（`git grep -E "sk-[A-Za-z0-9]{10,}"`）
- [ ] `cargo build --release` 零错误
- [ ] `cargo test` 通过
- [ ] WebUI 顶栏人格徽标/模型下拉正常
