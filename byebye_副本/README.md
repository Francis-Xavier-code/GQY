# GQY 核心架构速览

## 一句话定位
GQY 是一个 Rust 编写的命令行 AI 助手，支持多 LLM 后端、丰富工具系统、自主 Agent 集群。

## 核心模块

| 模块 | 职责 | 关键文件 |
|------|------|----------|
| **Agent** | 对话循环、上下文管理、模式切换 | `src/agent/mod.rs` |
| **LLM** | 统一 LLM 接口 (OpenAI/Pi) | `src/llm/mod.rs` |
| **Tools** | 工具注册、调用、权限控制 | `src/tools/mod.rs` |
| **Agents** | 子代理集群 (Kimi 式) | `src/agents.rs` |
| **State** | 对话历史存储 (SQLite) | `src/state/mod.rs` |
| **Memory** | 记忆系统、归档上下文 | `src/memory/mod.rs` |
| **Config** | 配置管理 | `src/config.rs` |
| **CLI** | 命令行解析、REPL | `src/cli/mod.rs` |

## 三种对话模式

```
┌─────────┬─────────────┬─────────────┐
│ Normal  │    Plan     │    Chat     │
├─────────┼─────────────┼─────────────┤
│ 完整工具 │ 只读工具    │ 轻量工具    │
│ 标准对话 │ 规划模式    │ 闲聊模式    │
│ 全部历史 │ 全部历史    │ 独立历史    │
└─────────┴─────────────┴─────────────┘
```

## 数据流简图

```
用户输入 → Agent → LLM 流式输出
                ↓
         检测工具调用 → 执行工具 → 继续对话
                ↓
         保存 Turn → 检查溢出 → 压缩/归档
                ↓
            返回结果
```

## 关键设计

1. **双 LLM 后端**: OpenAI Compatible (通用) + Pi RPC (本地模型)
2. **工具混合加载**: 按需加载，节省 token
3. **子代理集群**: 模型可自建/管理命名 agent，并行执行
4. **上下文三层管理**: 可见轮次 → 归档轮次 → 压缩摘要
5. **模式隔离**: Normal/Plan/Chat 独立工具集和历史
